# YOS-READER0｜Yuanli Reader Gateway

Governed USB-first device control gateway for the Yuanli OS Cognition Terminal experiment.

## Authority and safety boundary

This repository is a replaceable `CAPABILITY_ENGINE` and bounded C4 device execution adapter. It is not a method canon, knowledge canon, strategy authority, or autonomous reality-action authority.

G0 explicitly excludes arbitrary shell access, root, bootloader unlock, firmware flashing, DRM bypass, modification of the official Dedao app, arbitrary uninstall, and privileged system-settings mutation.

Authoritative design and cross-repository governance remain in `moonstachain/yuanli-strategy-soul`.
